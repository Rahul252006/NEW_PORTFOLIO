Executive Summary

In the health insurance domain, accurately estimating annual policy charges based on individual customer profiles is vital for actuarial underwriting, pricing accuracy, and risk mitigation. Traditional manual rule-based estimation can struggle to capture non-linear interactions between lifestyle behaviors (such as smoking) and physical indicators (such as Body Mass Index).

This project engineered an end-to-end predictive machine learning solution analyzing the Medical Cost Personal Dataset (US). The workflow covers every stage of data science engineering — from initial exploratory distributions to feature encoding, multicollinearity diagnosis via Variance Inflation Factor (VIF), regularization model comparison, and deployment of a production-grade Streamlit web interface on Render.

"By identifying non-linear interactions between smoking status and BMI, the final tuned Lasso Regression model isolates risk drivers while preventing overfit, providing instantaneous and reliable annual expense predictions."

Dataset Architecture & Variables

The model is trained on the US Medical Cost Personal Dataset, comprising individual health records with key socio-demographic and physical predictors:

Variable Type Description & Range
Age Numerical (Integer) Primary policyholder age (18 to 64 years)
Sex Categorical (Binary) Gender of policyholder (male / female)
BMI Numerical (Float) Body Mass Index ($kg/m^2$), baseline healthy range 18.5 to 24.9, extending up to 53.1
Children Numerical (Integer) Number of dependent children covered under insurance (0 to 5)
Smoker Categorical (Binary) Smoking status of policyholder (yes / no)
Region Categorical (Nominal) US Geographic region (northeast, northwest, southeast, southwest)
Charges (Target) Numerical (Continuous) Annual individual medical costs billed in US Dollars ($USD$)

Exploratory Data Analysis (EDA) & Key Analytical Insights

As a Data Analyst, inspecting distribution metrics and feature correlations revealed critical statistical patterns governing healthcare expenditure:

  • Smoking Status is the Primary Cost Driver: Statistical disaggregation shows smokers experience an average annual medical charge of **$32,050**, compared to **$8,434** for non-smokers — representing a ~380% surcharge driven by elevated medical risk profiles.
  • Interaction Effect between BMI and Smoking: For non-smokers, an increase in BMI exhibits a slight linear increase in charges. However, for smokers with a $BMI \ge 30$ (obese classification), charges spike exponentially past $40,000 annually.
  • Age Correlation: Age demonstrates a positive linear trend ($r \approx 0.30$), with baseline annual charges increasing by approximately $250 - $300 for each additional year of age.
  • Regional Distribution: Southeastern policyholders exhibited slightly higher variance in charges due to higher average BMI values relative to other regions.

18-Phase Machine Learning Workflow

The system was built following a 18-phase analytical framework:

Phase 01 — 04
Data Ingestion & Cleaning
Loaded data, audited null values (0 missing), verified data types, and parsed skewness across numerical columns.
Phase 05 — 06
Feature Engineering & Encoding
Applied One-Hot Encoding via pd.get_dummies() for sex, smoker, and region. Performed 80/20 train-test split.
Phase 07 — 09
Baseline Linear Model & VIF
Fitted Multiple Linear Regression. Computed Variance Inflation Factor (VIF) to confirm absence of multicollinearity.
Phase 10 — 13
Regularized Algorithms
Implemented K-Fold Cross Validation alongside Ridge ($L_2$), Lasso ($L_1$), and ElasticNet hybrid regression algorithms.
Phase 14 — 15
GridSearchCV & Benchmarking
Tuned hyperparameters with 5-fold GridSearchCV. Selected Lasso Regression for optimal $R^2$ and lowest generalization error.
Phase 16 — 18
Serialization & Render Cloud
Saved insurance_lasso_model.pkl and feature columns via joblib. Constructed Streamlit GUI and deployed on Render.

Model Evaluation & Performance Benchmarking

Models were evaluated across standardized regression metrics including Mean Absolute Error ($MAE$), Root Mean Squared Error ($RMSE$), and $R^2$ Score:

Model Algorithm MAE ($USD$) RMSE ($USD$) $R^2$ Score Status
Multiple Linear Regression $4,183.48 $5,796.28 0.783 Baseline
Ridge Regression ($L_2$) $4,180.12 $5,792.15 0.784 Evaluated
Lasso Regression ($L_1$ Tuned) $4,172.90 $5,788.42 0.786 ✅ Selected Final Model
ElasticNet Regression $4,245.10 $5,860.30 0.778 Evaluated

Model Selection Rationale: Lasso Regression achieved the optimal balance of minimizing large residual variance while performing implicit feature selection, shrinking redundant coefficient parameters effectively.

Streamlit Web Application & Render Cloud Deployment

To make the machine learning model accessible to non-technical stakeholders and insurance underwriters, an interactive web UI was engineered using Streamlit:

  • Dynamic Input Forms: Allows users to set Age, Sex, BMI, Children count, Smoker status, and Region with instant feedback.
  • Real-time Inference Engine: Converts user inputs into encoded feature arrays identical to the training schema before running inference against the serialized .pkl model artifact.
  • Cloud Deployment on Render: Configured requirements.txt and container settings for continuous deployment directly from the GitHub codebase repository.
