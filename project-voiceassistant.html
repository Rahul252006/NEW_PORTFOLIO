Core Features & Architecture

The system connects a high-performance React SPA frontend with a Python FastAPI asynchronous backend over native WebSockets (`/ws/conversation`). Token streaming and high-fidelity audio synthesis occur concurrently to achieve ultra-low human conversational latency.

Groq LPU LLM & ElevenLabs Integration

The conversation lifecycle uses `AsyncGroq` with `stream=True` to stream tokens directly over WebSocket frames (`assistant_started`, `assistant_delta`, `assistant_completed`).

  • Groq LLM Engine: Powered by `llama-3.3-70b-versatile` running on dedicated Language Processing Units (LPUs) for instant response initiation.
  • Dynamic Voice Gender Switching:
    • Female Voice: Mapped to `cgSgspJ2msm6clMCkdW9` (Jessica — Warm & Bright Female Voice).
    • Male Voice: Mapped to `txk8uOzZ0iCh0B9mFSRG` (Rahul S — Indian Conversational Male Voice).
  • Automated Free-Tier Fallback Handling: Automatically catches `HTTP 402 Payment Required` exceptions when restricted custom voice IDs are requested on free API tier keys, seamlessly re-routing to `IKne3meq5aSn9XLyUdCD` (Charlie — Deep Male) without throwing runtime errors.
  • Real-Time Preview Voice: Features an instant UI test button (`🔊 Preview Voice`) to preview voice characteristics before speaking.

Safeguards & Reliability Engineering

Real-time audio processing requires strict control over browser execution states to prevent overlap, stuttering, or memory leaks:

  • Zero-Overlap AbortController: Instantly cancels ongoing or slow `POST /api/tts` network requests whenever new speech is initiated or manual audio reset is triggered.
  • Instant Audio Reset (`activeAudioRef`): Pauses active HTML5 `
  • Turn Deduplication Guard (`lastSpokenTurnRef`): Time-bounded deduplication guard stopping duplicate `assistant_completed` events from re-triggering audio playback within 2 seconds.
  • Smart Markdown Cleaning: Regex preprocessing strips code blocks, emojis, bold markers, and stage directions (e.g. `(warm smile)`) so synthesized speech remains natural.

Full Tech Stack

Containerization Docker, Docker Compose Multi-stage production container configuration with health checks.

Production Deployment Setup

The system is packaged with production manifests for multi-cloud deployment:

  • Docker Compose: Single-command local orchestration (`docker compose up --build`) exposing frontend on port 5173 and backend API on port 8000.
  • Railway & Render Setup: Pre-configured manifests (`railway.json` and `render.yaml`) handling WebSocket CORS headers and environment injection.
  • DigitalOcean & Nginx Reverse Proxy: Includes Nginx configuration (`voice-assistant.conf`) for proxying WebSocket upgrades (`Upgrade $http_upgrade`).
