Overview & Business Problem

The automotive industry generates massive volumes of vehicle listing data daily. Buyers and dealerships require a fast, automated way to estimate price categories based on complex technical specifications. Manually pricing vehicles across thousands of listings is inconsistent and time-intensive.

Used car prices depend on numerous interconnected attributes:

  • Vehicle Identity: Brand, Model, Manufacturing Year
  • Mechanical Specs: Engine Specifications, Engine Power, Torque, Fuel Type, Transmission
  • Usage & Condition: Kilometers Driven, Vehicle Condition, Feature Packages
  • Market Data: Seller Type, Listing Information
"By training supervised classification algorithms on clean automotive data, this system automates vehicle valuation into discrete price categories, eliminating manual bias and leakage."

Dataset Architecture & Statistics

The source dataset was collected from CarDekho API listing endpoints, initially spread across multiple raw CSV files including cars_overview.csv, car_details.csv, car_details_merges.csv, and feature_dictionary.csv. The primary dataset utilized for training was car_details_merges.csv.

Data Cleaning, Feature Engineering & Preprocessing

API-scraped data frequently contains redundant endpoints, target leakage, and unparsed text strings. Cleaning steps included:

Phase 01 — Data Sanitization
Column Pruning & Leakage Removal
Removed duplicate columns, identifier keys, raw URLs, image attributes, metadata fields, and target leakage parameters.
Phase 02 — Missing Value Imputation
Adaptive Imputation Strategy
Dropped columns with high missing percentages. Applied median imputation for skewed numerical attributes and mode imputation for categorical specifications.
Phase 03 — Feature Extraction
Numeric & Text Parsing
Extracted numeric values for Engine Power (bhp), Torque (Nm), and Kilometers Driven from unstructured specification strings.
Phase 04 — Preprocessing Pipeline
Encoding & Scaling
Executed Label Encoding for categorical variables, feature scaling via StandardScaler, and an 80/20 train-test split.

Model Implementation & Comparison

Three classification models were trained and benchmarked to evaluate predictive accuracy across price categories:

Model Algorithm Role / Architecture Accuracy Score Status
Logistic Regression Linear Baseline Classification 75.63% Baseline
Decision Tree Captures Non-Linear Feature Interactions 79.79% Evaluated
Random Forest Classifier Ensemble Decision Trees with Bagging 83.87% ✅ Best Performing Model

Key Technical Insight: The Random Forest Classifier performed best by effectively handling high-dimensional feature interactions and reducing variance across non-linear automotive attributes.

Visualizations & Analytical Artifacts

Exploratory and diagnostic visualizations created during model development:

  • Price Distribution Analysis: Visualized price category spreads across vehicle brands and manufacturing years.
  • Missing Value Heatmaps: Identified and validated missing data clusters before and after imputation.
  • Correlation Matrix: Audited feature dependencies between engine capacity, power output, and price categories.
  • Confusion Matrix & Feature Importance: Confirmed engine power, manufacturing year, and kilometers driven as top predictive features.

Key Learnings & Future Enhancements

This project provided valuable experience in cleaning real-world API data, preventing target leakage, and evaluating classification pipelines.

Future Improvements: Integration of advanced gradient boosting frameworks (XGBoost, LightGBM, CatBoost), hyperparameter optimization via Optuna, Streamlit web app deployment, and model explainability using SHAP.
